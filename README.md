## Описание

Десктопное приложение для ведения личной коллекции фильмов.  
Позволяет добавлять фильмы с указанием названия, жанра, года выпуска и рейтинга,  
фильтровать их по жанру и году, а также сохраняет все данные в JSON-файл.

## Функциональность

- Добавление фильма с валидацией: год — целое число, рейтинг от 0 до 10.
- Отображение всех фильмов в таблице.
- Фильтрация в реальном времени по жанру (частичное совпадение) и по году (точное совпадение).
- Сохранение и загрузка данных из `movies.json`.
- Простой и интуитивный интерфейс на `tkinter`.
